# Практическая работа №1.1 — Sequelize + SQLite

## Предметная область

**Автомобили (cars)** — таблица для хранения информации об автомобилях.

### Поля таблицы:

| Поле | Тип | Описание |
|------|-----|----------|
| brand | STRING | Марка автомобиля |
| model | STRING | Модель автомобиля |
| year | INTEGER | Год выпуска |
| price | FLOAT | Цена в рублях |
| isAvailable | BOOLEAN | Доступен ли для продажи |
